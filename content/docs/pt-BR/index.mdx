O Tessera é um bot do Discord com dez módulos e um painel para configurá-los. Todo módulo começa
**desligado** e continua assim até você ligar; nada aqui depende de outra coisa daqui para ser útil.

## Duas portas, uma sala

Uma configuração mudada por comando de barra e a mesma configuração mudada no painel são **a mesma
configuração**. Não existe sincronizar, não existe importar, não existe botão de "enviar para o
Discord" — as duas são portas para uma config só, e a que você usou por último é o que o bot está
fazendo agora.

É por isso que você pode entregar o painel para quem nunca usou um comando de barra, entregar os
comandos para quem nunca abre um navegador, e os dois estarem certos. O detalhe de como isso é
sustentado está em [Como a config é guardada](/docs/concepts/config).

## Por onde começar

<Steps>
	<Step title="Adicione o bot">
		Uma tela de OAuth. Você precisa de **Gerenciar Servidor** no servidor onde vai adicioná-lo.
	</Step>
	<Step title="Confira a posição do cargo">
		Arraste o cargo do Tessera para acima dos cargos que ele vai gerenciar. Posição vence permissão,
		sempre.
	</Step>
	<Step title="Ligue um módulo">
		Boas-vindas costuma ser o primeiro, porque é o que os membros percebem.
	</Step>
</Steps>

## Convenções destas páginas

<Callout tone="info" title="As tabelas de referência são geradas">
	Toda tabela de **Opções** e toda lista de **Comandos** destas páginas é lida da declaração do
	próprio bot quando a página carrega. Elas não conseguem descrever uma configuração que o bot não
	tem, nem ficar para trás de uma que ele ganhou.
</Callout>

| Você vê           | Quer dizer                                                         |
| ----------------- | ------------------------------------------------------------------ |
| `código`          | Um valor literal, o nome de uma permissão, ou algo que você digita |
| **negrito**       | Algo com uma consequência que vale ler duas vezes                  |
| Um aviso azul     | Contexto que você provavelmente quer                               |
| Um aviso amarelo  | Um limite, ou algo que morde de leve                               |
| Um aviso vermelho | Algo que vai te morder                                             |
| Um cartão escuro  | O que sai no Discord, desenhado como o Discord desenha             |
