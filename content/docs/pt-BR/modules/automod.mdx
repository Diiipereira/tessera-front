O AutoMod confere toda mensagem contra as regras que você escreveu, na ordem em que elas estão, e
para na **primeira que dispara**. O que ele faz depois — apagar, avisar, advertir, castigar — é
escolha da regra.

Cargos e canais isentos são **"um destes"**, não "todos": basta o membro ter um dos cargos listados,
ou a mensagem estar num dos canais listados, para a regra não valer ali.

## Os gatilhos

| Gatilho             | O que ele vê                                   | Contável |
| ------------------- | ---------------------------------------------- | -------- |
| Palavras bloqueadas | Uma lista sua, comparada depois de desofuscar  | Não      |
| Convites            | Convites do Discord, inclusive disfarçados     | Não      |
| Links               | Endereços, com ou sem `https://` — veja abaixo | Não      |
| Menções             | Quantas menções numa mensagem só               | Sim      |
| Texto repetido      | A mesma mensagem repetida em sequência         | Sim      |
| Caixa alta          | A proporção de maiúsculas                      | Sim      |
| Spam                | Muitas mensagens numa janela curta             | Sim      |
| Anexos              | Arquivos enviados                              | Sim      |

Gatilho **contável** tem um limite que você escolhe: cinco menções, três repetições, 70% de
maiúsculas. Os outros disparam na primeira ocorrência.

## O gatilho de link tem dois níveis, e isso é de propósito

Procurar só por `https://` pega quase nada: quem divulga servidor escreve `discord.gg/x`. Mas tratar
qualquer `palavra.tld` como link puniria quem escreve `deploy.sh` ou `index.io` — num servidor de
gente que programa, isso é advertência em cima de conversa legítima.

## Disfarces que o AutoMod desfaz

Antes de comparar, o texto passa por uma limpeza. Ela desfaz quatro disfarces comuns:

```text
discord[.]gg/free     →  discord.gg/free
site . com            →  site.com
discord (dot) gg      →  discord.gg
https: //exemplo.com  →  https://exemplo.com
```

<Callout tone="warning" title="Isto não é à prova de evasão, e nada é">
	Homóglifo cirílico, caractere de largura zero e encurtador novo continuam passando. Cada volta
	dessa corrida pega a rodada anterior. O que se ganha é que o caminho preguiçoso — que é a
	esmagadora maioria — para de funcionar.
</Callout>

## Testando

| Onde            | Contra o quê                | Por quê                                       |
| --------------- | --------------------------- | --------------------------------------------- |
| Botão no painel | O rascunho que está na tela | Você está editando e quer ver antes de gravar |
| `/automod test` | As regras **salvas**        | No Discord não existe rascunho para testar    |

Spam e anexos aparecem como não testáveis: julgar os dois exige o histórico recente do canal e os
arquivos da mensagem, e um texto digitado não tem nenhum dos dois.

## Comandos

<Commands module="automod" />

| Subcomando        | O que faz                                                           |
| ----------------- | ------------------------------------------------------------------- |
| `/automod list`   | Mostra todas as regras, com gatilho, ação e se estão ligadas        |
| `/automod add`    | Cria uma regra: nome, gatilho, ação, e o limite se o gatilho contar |
| `/automod edit`   | Abre o seletor do próprio Discord para as listas da regra           |
| `/automod remove` | Apaga uma regra, escolhida pelo nome                                |
| `/automod test`   | Testa um texto contra as regras salvas                              |

O `add` cria a regra sem isenções. Cargos isentos, canais isentos, as ações e as palavras
bloqueadas se editam pelo `/automod edit`, que abre um modal já marcado com o que está configurado.

<Callout tone="info" title="Criar uma regra não liga o AutoMod">
	Com o módulo desligado a regra fica gravada e não age em ninguém — o `/automod add` avisa quando é
	esse o caso. Ligar é `/config automod enabled:true`, ou o interruptor no painel.
</Callout>

## Quando não funciona

| Sintoma                             | Causa provável                                                      |
| ----------------------------------- | ------------------------------------------------------------------- |
| A regra avisa mas nunca apaga       | Falta **Gerenciar Mensagens** no canal                              |
| Nada é lido                         | A intent **Message Content** está desligada no Portal do Discord    |
| Uma regra ampla come as específicas | A primeira que bate vence — mova a específica para cima             |
| Moderadores são pegos pelas regras  | Falta o cargo deles na lista de isentos                             |
| `deploy.sh` foi tratado como link   | Só acontece com barra ou `www.` — confira o texto exato da mensagem |
