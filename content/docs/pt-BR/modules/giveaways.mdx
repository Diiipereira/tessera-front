Um sorteio é uma mensagem publicada com um botão. Quem clica entra; quando o prazo vence, o Tessera
sorteia, edita a mensagem com o resultado e anuncia os ganhadores.

A mensagem é escrita por **uma função só**, porque dois processos a enviam: o bot pelo gateway e a
API pelo painel. Se cada um montasse o próprio texto, o mesmo sorteio teria duas aparências.

## Quem pode entrar

| Condição        | Como ela é lida                                        |
| --------------- | ------------------------------------------------------ |
| Cargos exigidos | **Um destes**, não todos                               |
| Nível exigido   | Só é consultado quando o sorteio realmente exige nível |
| Entradas bônus  | Cargos que valem mais de uma entrada                   |

O peso é **congelado na entrada**. Reconferir os cargos na hora do sorteio faria alguém perder o
peso por ter trocado de cargo depois de entrar, e obrigaria a buscar todo mundo no Discord no
momento mais caro.

## O sorteio

**Sem reposição** quer dizer que quem já foi sorteado sai do chapéu antes da próxima escolha, e o
total é refeito a cada volta. Sortear dois ganhadores usando o total da primeira volta daria um
resultado diferente — e errado.

<Callout tone="info" title="Quem já ganhou nunca volta ao chapéu">
	Um resorteio substitui a lista de ganhadores, então sem memória do que já foi ganho o segundo
	resorteio poderia devolver o prêmio ao primeiro ganhador. Se não sobrar ninguém elegível, o
	resorteio é **recusado** — a lista antiga fica de pé, em vez de a tela dizer que ninguém ganhou um
	sorteio que teve ganhador.
</Callout>

## Encerramento automático

Uma varredura a cada 15 segundos pega os sorteios vencidos. Não há temporizador acompanhando: um
sorteio pode durar um mês, e o teto de um `setTimeout` é de cerca de 25 dias — o timer seria um
caminho a mais que ainda precisaria da varredura.

Sorteio vencido é encerrado **mesmo se o bot não está mais no servidor**: o resultado é verdade e
fica gravado; só a parte do Discord é pulada.

## O aviso ao ganhador

A DM leva um **link para a mensagem do sorteio**, não o nome do servidor: ela chega fora de qualquer
servidor, então precisa dizer de onde veio — e o link diz de onde veio **e** leva de volta.

## O que não existe nesta versão

Sorteio agendado. A tela nunca teve onde escolher a hora de início, e a aba "Agendados" só podia
ficar vazia para sempre. Hoje um sorteio está **de pé** ou **encerrado**, e é só isso que as colunas
sabem dizer.

`/giveaway end` confere o **servidor**, não só o id: o Discord não prende ninguém às sugestões do
autocomplete, e sem a conferência daria para colar o id de um sorteio de outro servidor.

## Quando não funciona

| Sintoma                              | Causa provável                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| O sorteio não é publicado            | Falta **Enviar Mensagens** ou **Inserir Links** no canal                        |
| O botão diz que o sorteio não existe | Ele foi apagado, ou a publicação saiu e a gravação falhou                       |
| Ninguém consegue entrar              | Os cargos exigidos, ou o nível exigido, barram todo mundo                       |
| A contagem parece atrasada           | Ela é atualizada a cada cinco segundos; o encerramento reescreve o número final |
| O resorteio foi recusado             | Todo mundo que entrou já ganhou este prêmio                                     |
