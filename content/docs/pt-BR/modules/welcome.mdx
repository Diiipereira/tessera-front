O Boas-vindas escuta a entrada de membros e faz duas coisas, nesta ordem: entrega os cargos
automáticos e publica uma mensagem no canal escolhido. É o único módulo com um campo obrigatório —
sem canal, ele não liga.

## O que acontece quando alguém entra

Cada passo é independente do anterior. Um cargo que não pôde ser entregue não impede a mensagem, e
uma mensagem que não pôde ser publicada não desfaz o cargo. As duas falhas vão para o log do bot
com o motivo.

### Cargos que o bot não alcança

Um cargo só é entregue se estiver **abaixo** do cargo do Tessera na lista do servidor e o bot tiver
**Gerenciar Cargos**. O que não passa é registrado nominalmente no log — o módulo não silencia a
falha, mas também não deixa de entregar os outros.

## O que sai no canal

Em texto puro, com menção em linha:

<Message
	content="Bem-vindo ao Servidor de Testes, @novato! Passa no #regras antes de falar."
	time="hoje às 14:02"
/>

Em embed, com o mesmo conteúdo:

<Message
	embed={{
		color: '#5865f2',
		title: 'Bem-vindo ao Servidor de Testes',
		description: 'Você é o membro número 431.\nPassa no #regras antes de falar.',
		fields: [
			{ name: 'Comece por', value: '#apresentacoes', inline: true },
			{ name: 'Dúvidas', value: '#suporte', inline: true }
		],
		footer: 'Entrou agora'
	}}
	time="hoje às 14:02"
/>

<Callout tone="warning" title="Embed ligado significa embed só">
	Com **Usar embed** ligado, o texto puro **não** é enviado junto — a mensagem é só o embed. Se
	quiser uma linha acima do embed, ela precisa ser o próprio texto do embed ou uma menção fantasma.
</Callout>

## Variáveis

Duas, e valem em todo campo de texto do módulo — o texto puro e cada parte do embed: título,
descrição, nome e valor de campo, autor e rodapé.

| Variável   | Vira                                         |
| ---------- | -------------------------------------------- |
| `{user}`   | O membro que entrou (menção ou nome, abaixo) |
| `{server}` | O nome do servidor                           |

O que o bot não reconhece fica escrito como está, em vez de sumir: um `{usuario}` digitado errado
aparece na mensagem, e é assim que se percebe o erro.

## Os três modos de menção

| Modo         | O que o membro recebe             | O que `{user}` vira no seu texto |
| ------------ | --------------------------------- | -------------------------------- |
| **Nenhuma**  | Nada                              | O nome                           |
| **Em linha** | A menção dentro da mensagem       | A menção                         |
| **Fantasma** | Uma menção separada, apagada logo | O nome                           |

A menção fantasma existe para notificar sem deixar um ping permanente na mensagem: o bot publica a
menção sozinha, apaga, e só então publica a saudação. Nesse modo o `{user}` do texto vira o nome —
senão a pessoa seria mencionada duas vezes e só uma delas sumiria.

## Apagar a mensagem depois

O prazo é em segundos, de 1 a 86.400 (um dia). Zero e vazio significam a mesma coisa: não apaga.

<Callout tone="info" title="O prazo é contado pelo processo do bot">
	Se o bot reiniciar antes de o prazo vencer, a mensagem daquela pessoa fica no canal. É a única
	consequência de um reinício aqui, e ela é visível — não há registro perdido.
</Callout>

O embed não cabe numa opção de comando, então ele tem porta própria: `/config welcome edit:Embed`
abre um construtor em etapas dentro do Discord, com botões para corpo, autor, imagens, rodapé e

## Testando sem esperar alguém entrar

O botão **Enviar teste**, no topo da tela, publica a saudação no canal configurado usando você como
quem acabou de entrar. Pelo Discord é `/test module:Boas-vindas`.

O botão fica desativado enquanto houver alteração pendente: testar uma configuração diferente da
que está na tela seria enganoso. Com o módulo desligado ou sem canal, nada é enviado e o painel diz
qual dos dois é.

## Quando não funciona

| Sintoma                             | Causa provável                                                              |
| ----------------------------------- | --------------------------------------------------------------------------- |
| Ninguém é saudado                   | O módulo está desligado, ou a intent **Server Members** está off            |
| A mensagem não sai, mas o cargo vem | O bot não tem **Enviar Mensagens** no canal, ou o canal foi apagado         |
| O embed sai vazio                   | Todos os campos do embed estão em branco — embed sem conteúdo não é enviado |
| O cargo não é entregue              | O cargo está acima do Tessera na lista, ou falta **Gerenciar Cargos**       |
| `{user}` aparece escrito            | Está fora de um campo do módulo, ou o modo de menção é outro                |
