Um painel é uma mensagem publicada no canal que você escolher, com uma opção por cargo. Clicar num
botão — ou reagir com um emoji — entrega ou devolve o cargo, conforme o modo do painel.

## Os quatro modos

| Modo          | Clicar sem ter o cargo             | Clicar já tendo o cargo |
| ------------- | ---------------------------------- | ----------------------- |
| **Alternar**  | Entrega                            | Devolve                 |
| **Único**     | Entrega e tira os outros do painel | Não faz nada            |
| **Verificar** | Entrega                            | Não faz nada            |
| **Largar**    | Não faz nada                       | Devolve                 |

**Único** é para escolha exclusiva — uma cor, um time, um fuso. **Verificar** é para o botão de
regras: entra e não sai. **Largar** é o inverso, um painel que só remove.

## Publicar e editar

Um painel é publicado quando está **ligado, com canal e com pelo menos uma opção**. Editar e salvar
reescreve a mensagem já publicada em vez de publicar outra: o painel é salvo por id, e é o id da
mensagem que liga o botão ao painel.

Trocar o canal do painel publica uma mensagem nova no canal novo. A antiga não é apagada
automaticamente.

## Quando não funciona

| Sintoma                            | Causa provável                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| O cargo não é entregue             | Ele está acima do Tessera, ou falta **Gerenciar Cargos**                       |
| O painel não aparece no canal      | Está desligado, sem canal, ou sem nenhuma opção                                |
| Um botão antigo não responde       | O painel foi apagado — a mensagem fica, o painel não                           |
| A reação não faz nada              | Falta **Adicionar Reações**, ou o emoji não é de um servidor que o bot enxerga |
| Clicar de novo não devolve o cargo | O painel está em **Verificar**, que só entrega                                 |
