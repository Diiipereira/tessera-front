## O que cada uma faz

| Permissão                   | Usada por                                        | Sem ela                                        |
| --------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| `Ver Canal`                 | Todo módulo                                      | O bot não lê nem publica em lugar nenhum       |
| `Enviar Mensagens`          | Todo módulo                                      | Nada é publicado                               |
| `Inserir Links`             | Boas-vindas, Registros, Sorteios, Níveis         | As mensagens caem para texto puro              |
| `Gerenciar Cargos`          | Boas-vindas, Níveis, Cargos por reação, Economia | Nenhum cargo é entregue                        |
| `Moderar Membros`           | Moderação, AutoMod                               | Os castigos falham                             |
| `Expulsar Membros`          | Moderação                                        | O comando de expulsar é recusado               |
| `Banir Membros`             | Moderação                                        | O comando de banir é recusado                  |
| `Gerenciar Mensagens`       | AutoMod                                          | As regras avisam e registram, mas nunca apagam |
| `Gerenciar Canais`          | Tickets                                          | Nenhum canal de ticket pode ser criado         |
| `Anexar Arquivos`           | Tickets                                          | Os históricos não são guardados                |
| `Ver Registro de Auditoria` | Registros                                        | Os eventos saem sem dizer quem os causou       |
| `Adicionar Reações`         | Cargos por reação, Sorteios                      | Os painéis por reação não funcionam            |

## A primeira armadilha: hierarquia de cargos

As permissões do Discord são só metade da história. Um bot nunca age sobre um membro, nem entrega um
cargo, que esteja **acima do cargo mais alto dele** — nenhuma permissão passa por cima disso.

```text
Dono
Admin
Tessera          ← tudo abaixo desta linha pode ser gerenciado e entregue
Moderador
Membro
Silenciado
```

<Callout tone="danger" title="Administrador não é atalho">
	Dar Administrador não levanta a regra da hierarquia, e concede muito mais do que qualquer módulo
	usa. Posicione o cargo em vez disso.
</Callout>

A maioria dos relatos de _"o bot ignora meus moderadores"_ é isto.

## A segunda armadilha: permissão por canal

Uma permissão concedida ao **cargo** pode ser negada num **canal** específico. O bot pode ter
Enviar Mensagens no servidor inteiro e não conseguir escrever justamente no canal que você
configurou.

Por isso os módulos que enviam mensagem têm botão de teste: ele publica de verdade, e é a única
coisa que responde essa pergunta.

## Se você hospeda o bot

Duas intents privilegiadas precisam estar ligadas no Portal do Desenvolvedor do Discord, em
**Bot → Privileged Gateway Intents**:

| Intent            | Sem ela                                                       |
| ----------------- | ------------------------------------------------------------- |
| `Server Members`  | O evento de entrada nunca chega — Boas-vindas não dispara     |
| `Message Content` | O conteúdo das mensagens chega vazio — AutoMod e Níveis param |

A falha é **silenciosa**: o gateway conecta normalmente e os eventos simplesmente não chegam.
