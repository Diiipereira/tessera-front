---
title: Seu primeiro módulo
summary: Ligando o Boas-vindas de ponta a ponta, incluindo a parte que todo mundo erra.
---

Boas-vindas costuma ser o primeiro módulo porque o resultado aparece na hora. Isto percorre a
coisa toda, de desligado até uma saudação que os membros realmente veem.

<Steps>
	<Step title="Abra o módulo">
		Painel → **Módulos** → Boas-vindas. Toda página de módulo é como esta, então aprender uma vez
		basta.
	</Step>
	<Step title="Ligue">
		O botão no canto superior direito. Tudo abaixo dele continua editável enquanto está desligado,
		então dá para configurar antes de entrar no ar.
	</Step>
	<Step title="Escolha o canal">
		Onde a saudação é publicada. O módulo não pode ser ligado sem um, então este é o campo que
		decide se o botão funciona.
	</Step>
	<Step title="Escreva a mensagem">
		Use `{user}` para o membro que entrou e `{server}` para o nome do servidor. A prévia atualiza
		enquanto você digita.
	</Step>
	<Step title="Confira com uma entrada de verdade">
		Convide uma segunda conta, ou peça para alguém entrar de novo. A prévia mostra o formato, mas só
		uma entrada real prova que o bot tem as permissões de que precisa naquele canal.
	</Step>
</Steps>

<Callout tone="info" title="A mesma coisa pelo Discord">
	Todo passo acima tem um comando de barra. `/config welcome channel-id:#geral` faz o terceiro, e o
	painel mostra no instante em que você roda.
</Callout>
