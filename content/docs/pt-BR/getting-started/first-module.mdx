Boas-vindas costuma ser o primeiro módulo porque o resultado aparece na hora. Isto percorre a coisa
toda, de desligado até uma saudação que os membros realmente veem — e toda página de módulo funciona
como esta, então aprender uma vez basta.

## Pelo painel

<Steps>
	<Step title="Abra o módulo">Painel → **Módulos** → Boas-vindas.</Step>
	<Step title="Escolha o canal">
		Onde a saudação é publicada. É o único campo obrigatório do produto inteiro — o interruptor não
		liga sem ele.
	</Step>
	<Step title="Escreva a mensagem">
		Use `{user}` para quem entrou e `{server}` para o nome do servidor. A prévia ao lado atualiza
		enquanto você digita, com dados de exemplo.
	</Step>
	<Step title="Salve">
		A barra embaixo mostra quantos campos mudaram. Enquanto houver alteração pendente, o botão de
		testar fica desativado.
	</Step>
	<Step title="Ligue">
		O interruptor no canto superior direito. Nada é publicado enquanto ele está desligado, mas tudo
		continua editável — dá para configurar inteiro antes de entrar no ar.
	</Step>
	<Step title="Teste">
		O botão **Enviar teste** publica a saudação no canal de verdade, usando você como quem acabou de
		entrar. É a prova de que o bot tem as permissões que precisa **naquele** canal.
	</Step>
</Steps>

## Pelo Discord

Todo passo acima tem um comando. Estes três fazem a mesma coisa:

```
/config welcome channel-id:#geral
/config welcome message:Bem-vindo ao {server}, {user}!
/config welcome enabled:true
```

<Callout tone="info" title="O painel mostra no instante em que você roda">
	Não há sincronizar. Se a página estiver aberta, recarregue — o valor novo já está lá.
</Callout>

O comando altera **só** os campos que você citar. `/config welcome message:...` não desliga o
módulo nem apaga o canal.

## Se nada aparecer

| Sintoma                         | O que conferir                                                  |
| ------------------------------- | --------------------------------------------------------------- |
| O interruptor não liga          | Falta o canal — é o único campo obrigatório                     |
| O teste diz que não está pronto | O módulo está desligado, ou ainda sem canal                     |
| O teste falha no canal          | O bot não tem **Enviar Mensagens** ali; a prévia não prova isso |
| O cargo automático não vem      | Ele está acima do Tessera na lista de cargos                    |

## Depois disto

Cada módulo funciona sozinho, e a ordem é sua. [Registros](/docs/modules/logging) costuma ser o
segundo, porque ele mostra o que está acontecendo enquanto você configura o resto.
