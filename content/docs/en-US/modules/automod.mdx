AutoMod checks every message against the rules you wrote, in the order they sit in, and stops at
the **first one that fires**. What happens next — delete, warn, punish, time out — is the rule's
choice.

Exempt roles and channels mean **"any of these"**, not "all of them": one listed role on the member,
or one listed channel for the message, and the rule does not apply there.

## The triggers

| Trigger       | What it sees                                      | Countable |
| ------------- | ------------------------------------------------- | --------- |
| Blocked words | A list of yours, compared after unmasking         | No        |
| Invites       | Discord invites, disguised ones included          | No        |
| Links         | Addresses, with or without `https://` — see below | No        |
| Mentions      | How many mentions in one message                  | Yes       |
| Repeated text | The same message sent again in a row              | Yes       |
| Caps          | The share of uppercase letters                    | Yes       |
| Spam          | Many messages in a short window                   | Yes       |
| Attachments   | Files that were uploaded                          | Yes       |

A **countable** trigger carries a threshold you choose: five mentions, three repeats, 70% caps. The
rest fire on the first occurrence.

## The link trigger works in two tiers, and that is deliberate

Looking only for `https://` catches almost nothing: people advertising a server write
`discord.gg/x`. But treating any `word.tld` as a link would punish someone writing `deploy.sh` or
`index.io` — on a server full of developers that is a warning on top of a legitimate conversation.

## Disguises AutoMod undoes

Before anything is compared, the text goes through a cleanup that undoes four common disguises:

```text
discord[.]gg/free     →  discord.gg/free
site . com            →  site.com
discord (dot) gg      →  discord.gg
https: //example.com  →  https://example.com
```

<Callout tone="warning" title="This is not evasion-proof, and nothing is">
	Cyrillic homoglyphs, zero-width characters and new shorteners still get through. Every round of
	that race catches the previous one. What you buy is that the lazy path — which is the vast
	majority — stops working.
</Callout>

## Testing

| Where                | Against what        | Why                                             |
| -------------------- | ------------------- | ----------------------------------------------- |
| The dashboard button | The draft on screen | You are editing and want to see before you save |
| `/automod test`      | The **saved** rules | In Discord there is no draft to test            |

Spam and attachments come back as untestable: judging either needs the channel's recent history and
the message's files, and typed text has neither.

## Commands

<Commands module="automod" />

| Subcommand        | What it does                                                          |
| ----------------- | --------------------------------------------------------------------- |
| `/automod list`   | Shows every rule, with its trigger, action and whether it is on       |
| `/automod add`    | Creates a rule: name, trigger, action, and the threshold if it counts |
| `/automod edit`   | Opens Discord's own picker for the rule's lists                       |
| `/automod remove` | Deletes a rule, chosen by name                                        |
| `/automod test`   | Tests a piece of text against the saved rules                         |

`add` creates the rule with no exemptions. Exempt roles, exempt channels, the actions and the
blocked words are edited through `/automod edit`, which opens a modal already ticked with what is
configured.

<Callout tone="info" title="Creating a rule does not turn AutoMod on">
	With the module off the rule is stored and acts on nobody — `/automod add` says so when that is
	the case. Turning it on is `/config automod enabled:true`, or the switch in the dashboard.
</Callout>

## When it does not work

| Symptom                             | Likely cause                                                    |
| ----------------------------------- | --------------------------------------------------------------- |
| The rule warns but never deletes    | **Manage Messages** is missing in that channel                  |
| Nothing is read at all              | The **Message Content** intent is off in the Discord Portal     |
| A broad rule eats the specific ones | First match wins — move the specific rule above it              |
| Moderators get caught by the rules  | Their role is missing from the exempt list                      |
| `deploy.sh` was treated as a link   | That only happens with a slash or `www.` — check the exact text |
