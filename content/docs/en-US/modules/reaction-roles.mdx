A panel is a message posted in the channel you choose, with one option per role. Clicking a button —
or reacting with an emoji — hands the role out or takes it back, according to the panel's mode.

## The four modes

| Mode       | Clicking without the role               | Clicking while holding it |
| ---------- | --------------------------------------- | ------------------------- |
| **Toggle** | Gives it                                | Takes it back             |
| **Unique** | Gives it and removes the panel's others | Does nothing              |
| **Verify** | Gives it                                | Does nothing              |
| **Drop**   | Does nothing                            | Takes it back             |

**Unique** is for an exclusive choice — a colour, a team, a timezone. **Verify** is the rules
button: in and never out. **Drop** is the inverse, a panel that only removes.

## Posting and editing

A panel is posted when it is **on, has a channel, and has at least one option**. Editing and saving
rewrites the message that is already out there instead of posting another: the panel is saved by id,
and it is the message id that binds a button to its panel.

Changing a panel's channel posts a fresh message in the new channel. The old one is not deleted
automatically.

## When it does not work

| Symptom                           | Likely cause                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------ |
| The role is never given           | It sits above Tessera, or **Manage Roles** is missing                          |
| The panel never shows up          | It is off, has no channel, or has no options                                   |
| An old button does nothing        | The panel was deleted — the message stays, the panel does not                  |
| The reaction does nothing         | **Add Reactions** is missing, or the emoji is from a server the bot cannot see |
| Clicking again does not remove it | The panel is on **Verify**, which only gives                                   |
