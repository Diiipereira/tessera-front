Every week the Epic Games Store gives one or two games away. With this module on, Tessera posts each of
them in the channel you pick, with the store picture, the moment the offer ends and a link to claim it.

Epic usually swaps its free games on Thursdays at 15:00 UTC. The next game is already stored before the
swap, so the announcement goes out on the first sweep after it — within a minute.

When Epic gives two games in the same week, **one** message goes out with a card for each. The
"Next up" line only appears once the store has announced what comes next, and it can be turned off.

<Callout title="Turned the module on in the middle of the week?">
	The game that is still free is announced on the next sweep. There is no waiting for the next
	Thursday.
</Callout>

## What counts as a free game

Epic mixes free games, ordinary discounts, DLC and bundles in the same list. Tessera announces only what
is actually free:

| Announced                                                 | Left out                            |
| --------------------------------------------------------- | ----------------------------------- |
| A game whose final price is zero, inside the offer window | An ordinary discount, of any size   |
| A free bundle                                             | Free DLC for a game you may not own |
| The next free game, as a line in the post                 | An offer that has not started yet   |

The price is not shown. It changes from country to country, and the server language does not say where
its members are.

## Customizing the message

With the card on, each game becomes a card with the store picture. With the card off, each game becomes
a line of text. Leave it blank and Tessera writes its own, in the server language.

| Variable  | Becomes                                        |
| --------- | ---------------------------------------------- |
| `{game}`  | The name of the game                           |
| `{store}` | The name of the store                          |
| `{until}` | When the offer ends, in the reader's time zone |
| `{url}`   | The link to the game page on the store         |

## Testing

**Send a test** posts the current announcement to the saved channel, with a line naming who asked. The
test notifies nobody: the roles show up in the message, but no one gets pinged. If nothing is free at
the moment, the test shows the next game instead.

## Options

<Fields module="game-alerts" />

Everything can be set from Discord as well: `/config game-alerts` for the simple fields, and
`/config game-alerts edit:` for the roles, the stores and the card.

## When it does not work

| Symptom                             | Likely cause                                                        |
| ----------------------------------- | ------------------------------------------------------------------- |
| The module will not switch on       | No channel has been picked                                          |
| Nothing was posted on Thursday      | The bot cannot see or write in the channel, or lacks Embed Links    |
| The test says there is no game      | The store has no free game and has not announced the next one       |
| A game showed up again months later | The store gave it away again, in a new window — that is a new offer |
