## What each one does

| Permission         | Used by                                  | Without it                                   |
| ------------------ | ---------------------------------------- | -------------------------------------------- |
| `View Channel`     | Every module                             | The bot neither reads nor posts anywhere     |
| `Send Messages`    | Every module                             | Nothing is posted                            |
| `Embed Links`      | Welcome, Logging, Giveaways, Levels      | Messages fall back to plain text             |
| `Manage Roles`     | Welcome, Levels, Reaction roles, Economy | No role is ever handed out                   |
| `Moderate Members` | Moderation, AutoMod                      | Timeouts fail                                |
| `Kick Members`     | Moderation                               | The kick command is refused                  |
| `Ban Members`      | Moderation                               | The ban command is refused                   |
| `Manage Messages`  | AutoMod                                  | Rules warn and log, but never delete         |
| `Manage Channels`  | Tickets                                  | No ticket channel can be created             |
| `Attach Files`     | Tickets                                  | Transcripts are not kept                     |
| `View Audit Log`   | Logging                                  | Events go out without saying who caused them |
| `Add Reactions`    | Reaction roles, Giveaways                | Reaction panels do not work                  |

## The first trap: role hierarchy

Discord permissions are only half the story. A bot never acts on a member, nor hands out a role,
that sits **above its own highest role** — no permission overrides that.

```text
Owner
Admin
Tessera          ← everything below this line can be managed and handed out
Moderator
Member
Muted
```

<Callout tone="danger" title="Administrator is not a shortcut">
	Granting Administrator does not lift the hierarchy rule, and hands over far more than any module
	uses. Position the role instead.
</Callout>

Most reports of _"the bot ignores my moderators"_ are this.

## The second trap: per-channel permissions

A permission granted to the **role** can be denied in a specific **channel**. The bot can have Send
Messages across the whole server and still be unable to write in exactly the channel you configured.

## If you host the bot yourself

Two privileged intents have to be enabled in Discord's Developer Portal, under **Bot → Privileged
Gateway Intents**:

| Intent            | Without it                                              |
| ----------------- | ------------------------------------------------------- |
| `Server Members`  | The join event never arrives — Welcome never fires      |
| `Message Content` | Message content arrives empty — AutoMod and Levels stop |

The failure is **silent**: the gateway connects normally and the events simply do not arrive.
