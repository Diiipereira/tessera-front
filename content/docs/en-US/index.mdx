Tessera is a Discord bot with ten modules and a dashboard to configure them. Every module starts
**off** and stays that way until you turn it on; nothing here needs anything else here to be useful.

## The modules

| Module                                         | What it does                                         |
| ---------------------------------------------- | ---------------------------------------------------- |
| [Welcome](/docs/modules/welcome)               | A message and roles for whoever joins                |
| [Moderation](/docs/modules/moderation)         | Warn, timeout, mute, kick, ban — as numbered cases   |
| [AutoMod](/docs/modules/automod)               | Rules that read every message and act on their own   |
| [Logging](/docs/modules/logging)               | Fifteen server events, each in its own channel       |
| [Levels](/docs/modules/levels)                 | XP for talking and for voice, with a role ladder     |
| [Economy](/docs/modules/economy)               | A server currency, claims and a shop                 |
| [Tickets](/docs/modules/tickets)               | A button that opens a private channel with the staff |
| [Reaction roles](/docs/modules/reaction-roles) | Panels where members take and drop roles             |
| [Giveaways](/docs/modules/giveaways)           | A prize, an enter button and a weighted draw         |
| [Scheduled messages](/docs/modules/scheduled)  | Messages posted on the clock you set                 |
| [Free games](/docs/modules/game-alerts)        | The games Epic gives away, announced once per server |

## Two doors, one room

A setting changed by slash command and the same setting changed in the dashboard are **the same
setting**. There is no syncing, no importing, no "push to Discord" button — they are two doors into
one configuration, and whichever you used last is what the bot is doing right now.

That is why you can hand the dashboard to someone who has never used a slash command, hand the
commands to someone who never opens a browser, and have both be right. How that is held together is
in [How config is stored](/docs/concepts/config).

## Where to start

<Steps>
	<Step title="Add the bot">
		One OAuth screen. You need **Manage Server** on the server you are adding it to.
	</Step>
	<Step title="Check the role position">
		Drag Tessera's role above the roles it will manage. Position beats permission, always.
	</Step>
	<Step title="Turn a module on">
		Welcome is usually the first, because it is the one members notice.
	</Step>
</Steps>

## Conventions on these pages

<Callout tone="info" title="The reference tables are generated">
	Every **Options** table and every **Commands** list on these pages is read from the bot's own
	declaration when the page loads. They cannot describe a setting the bot does not have, nor fall
	behind one it gained.
</Callout>

| You see          | It means                                                         |
| ---------------- | ---------------------------------------------------------------- |
| `code`           | A literal value, the name of a permission, or something you type |
| **bold**         | Something with a consequence worth reading twice                 |
| A blue callout   | Context you probably want                                        |
| A yellow callout | A limit, or something that bites gently                          |
| A red callout    | Something that will bite you                                     |
| A dark card      | What goes out in Discord, drawn the way Discord draws it         |
